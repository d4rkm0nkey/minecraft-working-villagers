# Steuerung

[← Wiki-Start](../README.md)

Alles wird über das GUI der Workstation, das Träger-Menü und das [Dorfbuch](../dorf/dorfbuch.md) gesteuert. Keine Befehle, keine Config-Dateien für Spieler.

## Auswahl in der Welt

Ein eigenes Werkzeug gibt es nicht. Wo etwas in der Welt ausgewählt werden muss, startet ein Button im Menü die Auswahl: Das Menü schließt sich, dann wählt man per Rechtsklick aus.

- Arbeiter zuweisen: Button in der Stationsübersicht, dann Rechtsklick auf einen Dorfbewohner.
- Kisten verknüpfen: Button für Quell- bzw. Zielkisten, dann Rechtsklick auf Kisten (nochmal klicken entfernt sie). Rechtsklick auf die Workstation beendet die Auswahl und öffnet das Menü wieder.
- Transportwege des [Trägers](../berufe/traeger.md): „+ Neuer Weg“, dann Quelle und Ziel anklicken.

## Workstation-GUI

- Reiter „Auftrag“: Rezept- bzw. Modusauswahl (Woodcutter: Baumart; Mine: Abbaumodus).
- Reiter „Bereich“: Größe, Position und Visualisierung an/aus.
- Reiter „Kisten“: verknüpfte Quell- und Zielkisten mit Koordinaten.
- Reiter „Personal“: zugewiesener Arbeiter, Lohn, Entlassen-Button.

## Grenzen

- Bereich und Kisten müssen innerhalb von z. B. 32 Blöcken um die Workstation liegen. Ausnahme Mine: Die Reichweite gilt ab dem letzten Depot des [Grubenlogistikers](../berufe/grubenlogistiker.md).
- Eine Workstation = ein Arbeiter (wie Vanilla-POI). Mehr Arbeiter brauchen mehr Stationen.
- Optional: Schilder als Wegmarken/Filter, z. B. ein Schild „Nur Eiche“ an der Zielkiste.
