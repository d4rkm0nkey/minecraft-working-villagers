# Working Villagers – Wiki

Working Villagers macht Dorfbewohner zu bezahlten Angestellten, die Rohstoffe wie Holz, Stein und Erze automatisch beschaffen. Automatisierung entsteht durch Menschen an Workstations, nicht durch Maschinen.

Dieses Wiki ist das Konzept des Mods, aufgeteilt in verlinkte Seiten. Alle Zahlen sind Startwerte für Playtests.
